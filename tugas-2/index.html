Tentang Proyek

Website portofolio ini dirancang dan dikembangkan sebagai pemenuhan Tugas Akhir Kursus Dasar Pemrograman Web dari Dicoding. Proyek ini mengimplementasikan standar struktur semantik HTML modern serta teknik tata letak CSS Flexbox untuk memastikan tampilan yang bersih, rapi, dan adaptif di berbagai ukuran perangkat.
